## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Set up environment
cp .env.example .env
# Edit .env with your actual keys

# 3. Start database & Redis (Docker)
docker-compose up -d db redis

# 4. Run migrations
npm run migrate

# 5. Seed demo data
npm run seed

# 6. Start the server
npm run dev
```
